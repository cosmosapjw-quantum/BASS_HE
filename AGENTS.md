# Research execution contract
This is a paper-derived independent implementation, NOT the authors' ARSENY code.
Preserve source statements separately from derivations, numerical evidence and conjectures.
Audit -> derivation -> explicit approximations -> tests -> pilot -> bounded claim.
Never certify a branch from duplicate-root equality alone. Never integrate the identity probability tail as an elastic cross section.
Keep exponent policies and upper-shell sink semantics explicit. No physical production claim from stochasticity or same-code replay.
Sandbox first; heavy-only local handoff after measured pilot. Cache content identities, not arbitrary rounded keys. Atomic write+fsync, preserve failure records.
Do not rerun unchanged scientific suites without an affected dependency; add tests for changed assumptions and imported data.
No public redistribution of attached source PDFs. Preserve bibliographic metadata and SHA256 instead.
