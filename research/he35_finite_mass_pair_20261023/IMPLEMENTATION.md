# HE35 implementation handoff

Python `matrices` returns thermal and STF generators plus ascending STF relaxation rates. `sources` returns full drifting raw and central tensor sources and pair forces. C99 `he35_pair` supplies portable row-major scalar matrices/rates; each LRS STF amplitude obeys this matrix. Compile without fast-math. SI pressure, kg, m^-3, proper seconds; caller κ in m³/s. Inputs must be finite, positive masses/densities, nonnegative κ, symmetric PSD pressure. Tensor roundoff tolerance is 64 machine epsilon times maximum absolute entry, without clipping. Nonrepresentable matrix outputs are rejected. Positive finite inputs beyond binary64 intermediate range are not supported except exact κ=0, which returns zeros after input validation.

`results.json` records 100 checks with maximum normalized error 1.8670464648487782e-15. The independent event oracle constructs individual outgoing velocities by elastic center-of-mass scattering, using six axis directions (exact for degree-two angular moments), then sums arbitrary finite incoming distributions. Eight deterministic cases check tensors, forces, energy, species swap, drift heat and common-bulk matrices. Other controls check weighted STF negativity/symmetry, equal masses, eigenvalues, equilibrium, Lorentz limit, invalid inputs and C parity on five fixtures. No ODE or empirical rate is used.
