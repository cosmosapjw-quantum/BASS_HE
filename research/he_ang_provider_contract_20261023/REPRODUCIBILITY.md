# Saved-evidence reproduction and resource accounting

The default resume operation verifies saved evidence; it does not rerun science. Restore the capsule unit and its stage_archives, preserve the frozen CONTRACT.json/BUDGET.json, then inspect RESOURCE_LEDGER.json, DAG.json and both independent reviews. Use `python verify_saved.py --unit <unit> --archive-dir <stage_archives> --output <new-uncovered-report.json>`. The verifier uses only the standard library and reads hashes, receipts, archived bytes and the DAG. It never imports science or accesses the network.
