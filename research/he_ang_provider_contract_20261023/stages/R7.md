# R7 판별 검증

`run_bounded.py --label R7_exact_witness -- python theory/check_witness.py`를 실제 실행했다. 새 exact rational script는 provider 구현을 import하지 않는다. 두 질량/좌표 설정의 A/B 각8event를 사용하고 모든 값과 기대식·판정을 raw stdout에 보존했다.

사건별 momentum/energy shell, exchange, full discrete inclusive marginal, 종별 R/C12/D, sigma-weighted recoil 식, 직접 event boost와 raw-moment transform, signed reaction count 및 boost 뒤 전체 net energy를 검사했다. 정확 predicates 전부 PASS와 exit0은 WITNESS_RECEIPT에 기록했다. 구체적인 수와 실제 CPU/wall/RSS는 그 receipt와 누적 RESOURCE_LEDGER가 권위다.

연속 azimuth identity는 analytic proof로 유지하고 유한 quadrature 자체를 연속 데이터로 해석하지 않는다. 경험적 source 검증, X1 32fixture 또는 HE38 재실행은0이다.
