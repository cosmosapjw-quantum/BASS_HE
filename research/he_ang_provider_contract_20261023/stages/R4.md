# R4 가설·표현 탐색

Joint event와 certified moment 경로를 비교하고, 실제 구현은 exact discrete event accumulator와 source metadata precheck로 결정했다. Boost에는 N/P/R, recoil STF에는 C12 또는 같은 law recoil certificate가 필요하다. 완전 event table을 저장한 뒤 모든 소비자에서 재적분하는 의무는 없으며, 적분된 fixed-size moments를 재사용할 수 있다.

판별용 A/B rational8event×2 구성과 연속 azimuth proof를 분리했다. O(n) moment accumulation과 O(1) frame transform의 구조는 유도된 비용 특성이며 실측 benchmark 주장이 아니다.

다음: R5에서 보존식·cross tensor·frame·source normalization을 완결한 정식 유도로 연결한다.
