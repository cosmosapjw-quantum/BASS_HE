# R1 연구 위치·계약

HE-ANG-CONTRACT는 고정 중앙 인계의 HE-ANG 내부 공급자 계약 단위다. `CONTRACT.json`에 scope, 의존성, 완료 기준과 no_merge/no_activation을 동결했다. HE-X1은 COMPLETE_SCOPED로 재사용한다.

현재 HE38 HEAD와 AGENTS, 중앙 HEAD, 병렬 ANGTHERM02 소유자 HEAD 및 이전 두 provider 백업 metadata를 `evidence/preflight/R1.json`에서 확인했다. HE38 capsule 262 payload를 복원했으며 과학 재실행은 0이다. 이전 작업공간 대신 archive-derived projection을 사용하고 실제 remote Git ref를 권위로 기록한다.

새 계약 검증만 CPU10s/wall30s/address-space256MiB로 동결했다. HE-X1의 실패 CPU UNKNOWN_NOT_ZERO 및 다른 단원의 누적 비용·한도는 전송하거나 초기화하지 않는다. physical provider scan, IVP, benchmark, render는 이 단위에서 0이다.

다음: R2에서 fixed-pin 재사용 근거와 후보의 열린 source 의존성을 정렬한다. 전체 물리 목표의 완료율은 이 20단계 비율로 산정하지 않는다.
