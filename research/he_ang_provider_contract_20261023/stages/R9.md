# R9 정식 결과·코딩 연결

CODING_CONTRACT와 EQUATION_CODE_MAP에 입력·출력·normalization·정확 비교 기준 및 각 구현 함수의 근거를 연결했다. Fixed-size raw moments를 통해 같은 law의 사건 합산 뒤 frame 변환을 재사용한다. 기존 X1 algorithm evidence와 이번 candidate certificate의 identity를 별개로 요구한다.

물리 source-content 판단과 metadata 구조 검사는 구별한다. 모든 executable precheck 상태는 empirical_admission/runtime_activation=false를 유지한다. 실제 arbitrary TDCS 적분은 이번 단위의 구현 완료 기준에 포함하지 않는다.
