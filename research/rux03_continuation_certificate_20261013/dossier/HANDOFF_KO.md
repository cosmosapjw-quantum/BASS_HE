## 다음 이론 루프의 구체적 시작점

**`HERE_RUX03_PREDICTOR_TUBE_AND_REANCHORED_FAMILY_07`**를 시작한다.

1. 현재 고정 old-state branch의 실제 source·정의역·H certificate를 재사용한다. Full Jacobian에 맞춘 A와 nonzero predictor \(\bar X(h)\)를 구성한다.
2. 서로 연결할 두 parameter tube의 center/radii/parameter interval을 명시한다. 각 tube의 physical inclusion을 먼저 확보한 뒤 full-tube Jacobian majorant를 증명한다.
3. 실제 exact/outward arithmetic으로 \(Y+Zr<r\), \(q_r<1\)을 두 구간 전체에서 보인다. 이전 단순 self-map ceiling \(1/B\)를 넘는 end parameter 또는 명시적으로 개선된 state enclosure를 목표로 한다. 같은 cube를 두 구간으로 나누는 bookkeeping을 새 구성으로 세지 않는다.
4. 공통 parameter에서 endpoint box nesting이나 공통 인증 root enclosure를 실제로 보여 같은 branch임을 연결한다.
5. 그 이후 previous-state input도 명시적 compact physical family로 확장한다. Affine reanchoring의 동등성, source/input sensitivity, 반올림 및 잔차 오차의 uniform transport를 유도한다. Old state를 갱신하는 여러 time step의 history와 현재 h-branch는 각각의 조건을 갖는다.

다음 완료 근거는 적어도 하나의 명시적인 full-rate tube pair와 실제 부등식, branch 연결, family/reanchoring의 정식 결과 및 coding handoff다. 단순 IFT 재진술이나 문헌 목록으로 완료하지 않는다. Native production coding이 없더라도 수학적 구성을 진행할 수 있으며, 실제 executable replay를 주장하려면 해당 구현 identity와 경로 증거가 별도로 필요하다.
