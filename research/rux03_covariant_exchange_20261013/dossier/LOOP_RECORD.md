## 검토와 방법 교정

- **R6-C01, source 대응 명시:** 방향을 분해한 null photon과 azimuth 평균 μ ring을
  구별하는 문단을 root proof에 추가했다. first/second moments가 이미 주어진
  식과 일치하며 새 계산은 필요하지 않았다.
- **R6-C02, source work 역할:** 현재 `work_ref`를 순간 work 도함수로 명시했다.
  현재 ODE 누적과 다음 endpoint-energy BE map의 exact discrete work를
  구별하도록 REPORT 문구를 교정했다. 유도된 식은 바뀌지 않았다.
- **R6-C03, 실제 escape 채널:** `Q_esc`는 고정 consumer의 RR/DR binding과
  captured-kinetic powers의 합으로 명시했다. 병렬로 나열했던 일반 cooling
  표현을 좁혀 추가 radiative channel이 있는 듯한 해석을 제거했다. 채택한
  사건률·에너지 식과 실행 입력은 바뀌지 않았다.
- **Execution setup:** 초기 package 부재와 잘못된 namespace, default/native
  canonicalization 및 differential MakeRule 호출의 실패를 보존했다. 지원되는
  pure Wolfram xPerm backend와 explicit indexed rules를 사용했다. 물리 가정과
  target equations는 이 교정에서 바뀌지 않았다.

연구 범위·정확도를 바꾸는 새로운 policy override는 없었다. 앞선 근거의
identity가 같은 부분은 재사용했고, 실제 변경·실패에 필요한 전이만 다시
살폈다. 모든 ODE/native 작업을 THEORY 완료의 선행 조건으로 추가하지 않았다.
