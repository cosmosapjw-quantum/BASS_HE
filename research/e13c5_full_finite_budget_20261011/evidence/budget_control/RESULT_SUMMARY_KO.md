# E13C5 전체 유한합 오차 예산: 구현 결과 요약

PR20의 mode별 2,440개 node 전체 결과에, 이미 검토된 OFF 0·700의 N512 구간 두 개를 직접 대입했다. 입력 raw를 한 번 읽으며 해시를 검증하고, 각 mode의 선택 네 경로와 나머지 2,436개 경로를 분해했다. 모든 계산은 저장된 구간 끝점에 대한 정확한 유리수 연산이며, 새로운 계수 평가·ODE·native·gas 계산은 0회다.

이번 결과의 핵심은 전체 유한합에서 두 OFF 정밀화가 줄이는 폭은 ppm 수준이라는 점이다. 선택 네 경로만 보면 큰 개선이지만, 전체 폭은 나머지 2,436개 경로에서 거의 전부 발생한다. 현재 입력으로 전체 유한합 보정 부호는 이미 모든 mode와 17개 보정량에서 확정된다.

## 실행과 검증

- 실제 저장 결과 처리 1회: 34.757663469초, 최대 RSS 171,196 KiB. Exit 0.
- 총 7,320개 경로, 14,652개 segment, PR19 재사용 12경로·36segment, N512 교체 2경로, 유지 7,318경로.
- 279,451개 범위 한정 확인 + 29개 합성 대조 통과. 실패 0개.
- 기존 PR20의 물리 및 로컬 구간 타당성 심사를 재실행한 것이 아니다. 입력 동일성, 재사용 구간 의미, 정확한 합과 분할, 교체 호환성과 부호·폭 예산을 확인했다.
- 모든 OFF 34개 지표(절대량 17개, 보정량 17개)의 새 전체 구간은 기존 전체 구간 안에 들어간다. KF와 GM은 정확히 동일하게 유지된다.
- PR20에 게시된 전체 per-step 구간과의 별도 비교는 mode별 16개 절대량에 대해 포함 관계를 확인했다. final photon은 step 2 stock만, 순간 누적량은 step 1+2의 transaction 합이다. per-step anchor가 inter-step seam을 포함하지 않으므로 anchor는 이 비교에서 제외했다.

## 전체 유한합 보정 부호와 구간

보정은 continuous minus captured segment 기준이다. native 전체 aggregate 차이 또는 continuum quadrature 오차로 해석하면 안 된다. 아래 구간 끝점은 정확한 유리수 결과를 읽기 좋게 반올림한 표시값이다.

|---|---|---|---|
| OFF | [4.827055209445e-13, 4.827676245639e-13] | [8.847799613141e-12, 8.849003863531e-12] | [-2.603095871717e-12, -2.602704755973e-12] |

세 mode 모두 P_final, energy_eV, QN, QE_eV, HeII의 A/B/H 보정이 엄격히 양수다. HI·HeI의 A/B/H, 종별 합 A/B/H, Z_eV 보정은 엄격히 음수다. 17개 보정량 × 3 mode 중 미확정 부호는 0개다. 이 부호는 두 OFF 교체 전에도 확정되어 있었고, 이번 교체가 새롭게 부호를 결정한 것은 아니다.

## 범위와 다음 단계

PR20의 mode별 2,440개 전체 finite captured node cover는 재사용 완료 상태다. 남은 요구는 “미계산 finite node를 모두 계산”하는 것이 아니다. 필요한 관측량을 기준으로 이미 저장된 폭 예산에서 다음 제한된 정밀화 대상을 고르거나, continuum spectral quadrature에 필요한 구간 전체 가정과 bound를 별도 정식화하는 일이다.

continuum spectral quadrature 오차, cosmological 시간 수렴, 실제 gas evolution, photon/heat/recoil 전달, physical/global/production admission, receiver adoption은 계속 HOLD다. 실제 NCP 실행은 이 Chat 작업에서 수행하지 않았다. 이 보고서는 후보 구현자의 실행 요약이며 최종 독립 결정 심사를 대신하지 않는다.
