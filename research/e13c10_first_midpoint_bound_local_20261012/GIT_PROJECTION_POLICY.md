# Git review projection

The complete package is the authoritative payload. The additive GitHub draft projection includes source, contracts, state, reports, theory, plots, controls scripts, compact control evidence, independent decision and review, saved raw comparisons, execution receipts and the full PACKAGE_MANIFEST.

The projection omits dependency ZIPs, every raw captured RESULT.json, large manufactured CONTROL_RESULTS.json over500,000bytes, and binary toy fixture archives. They remain unchanged in the COMPLETE backup. A generated external GIT_PROJECTION_INDEX.json records every package path, bytes, SHA256 and include/omit reason. It also binds the actual complete archive and transfer manifest, so the omitted exact raw files can be recovered without a new science run or user attachment.

Git blob SHA1/tree identity is checked against the local bytes for every projected file. Remote upload ACK/name/size and actual archive-chain restore are recorded separately. The new branch is additive on the recorded E13C9 draft head; no merge, rebase, force push or original source change is part of this delivery.
