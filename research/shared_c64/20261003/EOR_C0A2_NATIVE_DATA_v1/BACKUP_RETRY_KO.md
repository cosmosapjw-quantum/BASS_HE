# C0A2 게시 및 백업 재시도

2026-10-03. 사용자 요청에 따라 봉인된 C0A2의 공개 mapping 12개 파일을 바이트 동일하게 게시한다. 이번 기록까지 신규 13개 파일이며 기존 branch/파일을 덮어쓰지 않는다. public Git에는 원 CSV/PDF나 generated 숫자 배열을 넣지 않는다. 공개 시험은 private 원자료/input lock/부모 DAG가 있어야 실행 가능하다.

과학적 원본: BASS_HE_EOR_C0A2_NATIVE_DATA_20261003_v1.zip, 3172184 bytes, SHA256 a2060d7842636fb5d08cfbb27c263d30ef78728bae0ebf4bda734c5f11697eb1. CRC와60개 payload 해시를 실제 재확인했다. 변경 없는 과거52개 scientific tests는 다시 돌리지 않았다. 기존 시험 성공은 부모 evidence의 상태이고 이번 재시도는 byte/publication verification이다.

Drive에는 새 객체의 성공 ACK와 동일 크기를 확인했다. Dropbox 원래 경로에는3160090-byte 동명 파일이 있어 그대로 보존했다. 그 내용과 관계는 미확인이다. 이번 봉인본은 BASS_HE_EOR_C0A2_NATIVE_DATA_20261003_sha_a2060d784263.zip으로 저장했고 completed/ID/3172184-byte 크기를 확인했다. 원격 restore는 수행하지 않았다. private object IDs와 최종 commit/tree는 detached receipt가 소유한다.

C0A3는 별도 namespace에서 source-native 보간과 partial-support rate 기능만 진행한다. Bianchi 기하/수송/유체 코드는 rei_bianchi가 소유한다. source uncertainty/license/isotope/per-u metadata는 미확정이며 scientific_PROMOTE=HOLD, Eq55=NOT_RUN, production_default_change=NOT_AUTHORIZED를 유지한다.
