R8 fresh Wolfram normalization checks

Assumptions: d>=0, v>0, g>=0, F>0; p is a probability in a two-state stochastic block.

1. If d = pi g^2/(4 F), then for amplitude exp[i(s+i d)/v]:
   |A|^2 = exp[-2 d/v] = exp[-pi g^2/(2 F v)].

2. Eq.(52)-style p=exp[-d/v] gives p^2=exp[-2 d/v].

3. But using the same reversible stochastic block M=[[1-p,p],[p,1-p]] twice gives
   (M^2)_{12} = 2 p (1-p), not p^2 in general.
   Equality 2p(1-p)=p^2 occurs only at p=0 or p=2/3.

4. With an absorbing upper state M_a=[[1-p,0],[p,1]], two passages transfer p(2-p), not p^2.

Consequence: Eq.(50)'s repeated probability matrices do not algebraically explain Eq.(55)'s factor-two exponent by themselves. The factor-two formula is instead consistent with modulus-square of a complex-action amplitude and with Richter-Solov'ev's squared-gap Landau-Zener/Stueckelberg parameter.

This is a symbolic algebra check only. It is not a source-code audit or production calculation.
