# C6 구현 검증

새 provider 6/6 groups와 24개 invalid-input rejection, 새 net bridge 7/7 groups와 25개 rejection을 실제 실행했다. 추가로 양의 source의 underflow/overflow 2개를 거부했다.

Immutable arrays, 단위, H0/H+ index, density census, zero 상태와 표현 가능성을 검사했다. 최초 실행 receipt를 보존했으며 기존 suite는 반복하지 않았다. 공개 단원으로 복사한 component 파일 43개가 원본 bytes와 일치한다.

실행 receipt와 `evidence/COMPONENT_COPY_IDENTITY.json`이 근거다. 게시와 백업은 `delivery/C6_ACK.json`에 기록한다.
