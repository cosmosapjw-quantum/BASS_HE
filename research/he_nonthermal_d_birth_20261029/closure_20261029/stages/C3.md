# C3 — 수치 설계

Fraction 적분으로 bin counts·reduced moments와 raw trace remainder를 정확 계산한다. Jensen/secant 교집합으로 반환 폭의 기준을 보존한다. 이는 임의 reduced rational partition에서 보존적이고 grid quadrature 오차가 없다. N0–6 contraction·asymmetric-bin midpoint counterexample·50/80digit independent quadrature를 판별 검사로 선택했다. 물리 입력 불확실성은 별도 null 상태다.
