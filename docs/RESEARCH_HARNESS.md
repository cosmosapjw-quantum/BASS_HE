# Evidence-based research harness

Model-independent contract used in the requested GPT research/coding loop. This is a recorded workflow, not a claim that an inaccessible model-specific agent ran.

1. **RECOVER**: exact bytes, archive hashes, manifest, existing run state; never infer from transcript-only PASS.
2. **AUDIT**: model assumptions, mathematical sufficiency, discretization, implementation, environment separately. Create counterexamples before fixes.
3. **DIVERGE**: compare independent spectral methods, gauge/coordinate choices, coherent vs stochastic models, trajectory models, and compiled/batched/parallel routes. Distinguish a better model from a faster implementation of the same model.
4. **DERIVE**: prove the identity used by each exact optimization. State units, invariant subspaces, finite-observable definitions and error propagation.
5. **CONVERGE**: select a bounded change set; preserve alternative paths and conditions under which they become necessary.
6. **RED/GREEN**: recorded failing tests, smallest changes, fresh affected verification. Do not relabel mock/conservation-only tests as physical validation.
7. **PILOT**: sandbox first; actual runtime, error and memory before a heavy local handoff. Separate cold certification cost, reusable geometry cost and matrix propagation cost.
8. **CLAIM**: source-supported / directly derived / numerically checked / implementation verified / open are separate fields. Stochasticity, approximate invariants and same-code replay never prove physical validity.
9. **PUBLISH**: commit/tree identities plus actual provider acknowledgement. Never replace push/restore evidence with a local checksum.

## Gates used in this loop

- A01 fails on an ordinary duplicate root even when the old coalescence residual is zero.
- EP acceptance requires F residual, Jacobian rank loss, simple-fold transversality/curvature, one-loop swap and two-loop return.
- No uncertified endpoint gap is forced to zero.
- No failed geometry value is imputed.
- Numerical fidelity, physical-model adequacy, and source convention resolution have separate stop conditions.
- Positive quadrature weights and split discontinuities are necessary structure, not sufficient convergence proof.
- Full EQ54 stops open when any material indexed-state component is unresolved, even when a total looks stable.
- Public repository excludes raw source PDFs, credentials, provider download URLs and unrelated personal files.
