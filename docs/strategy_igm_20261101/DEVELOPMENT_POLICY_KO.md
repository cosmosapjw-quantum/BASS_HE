Report these separately: (a) canonical accepted nodes from the 88-node owner; (b) working/provisional nodes; (c) source-backed physical predictions; (d) optional model/derived rows; (e) tests/validation; (f) publication/backup. Never add R/C stage files or datasets to the numerator of (a). Existing reported baseline is central 28/88 and HE 14/18, with physical delta 0.

One concise objective → evidence → failure/uncertainty → next-action record suffices for a bounded unit; large multi-stage document sets only when they actually contain substantively distinct work. Reuse valid historic evidence, run changed-path tests, perform one bounded risk-justified independent review. Do not replace physical execution with repetitive audit/backup loops or impose new arbitrary gates. No unverified CI, same-author review or byte readback substitutes for science.
